# The Travel Atelier

A responsive travel-agency landing page for visa assistance, flights, hotels, and car rental. The site uses an editorial visual style with cinematic travel photography, accessible navigation, a validated WhatsApp inquiry form, and reduced-motion-aware GSAP animations.

## Stack

- React, TypeScript, Vite, and TanStack Router
- Tailwind CSS
- GSAP and ScrollTrigger

## Development

Requires Node.js and npm.

```bash
npm install
npm run dev
```

## Checks

```bash
npm test
npm run lint
npm run build
```
