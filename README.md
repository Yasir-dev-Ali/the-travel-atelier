# The Travel Atelier

Build a premium, conversion-focused travel agency landing page using Next.js, TypeScript, Tailwind CSS, GSAP, and ScrollTrigger.

Services: Visa Assistance, Flight Ticket Booking, Hotel Reservations, and Car Rental.

Design: Luxury editorial aesthetic with cinematic travel photography, elegant typography, a navy, ivory, and teal color palette, spacious layouts, and polished responsive UI/UX. Avoid generic templates and excessive cards.

Landing Page Sections:

Animated hero with an inspiring travel image, compelling headline, CTA buttons, and travel inquiry form.

Four travel services with custom visuals and hover interactions.

Featured destinations with immersive image layouts.

Why Choose Us section highlighting service benefits without unsupported claims.

Simple step-by-step booking process.

Frequently Asked Questions accordion.

Strong contact/WhatsApp inquiry CTA.

Professional footer with navigation and contact details.

Animations: Use GSAP for cinematic hero reveals, staggered text, image masks, scroll-triggered transitions, subtle parallax, and smooth hover effects. Respect reduced-motion preferences and ensure excellent performance.

Technical Requirements: Next.js App Router, TypeScript, Tailwind CSS, reusable components, accessible mobile navigation, responsive layouts, optimized images, SEO metadata, and validated inquiry forms.

Important: Build the actual working landing page, not just a mockup. Use realistic travel imagery, polished spacing, clear visual hierarchy, and conversion-focused design. Do not invent company details, reviews, prices, or booking availability. Test mobile, tablet, and desktop layouts, and run lint, TypeScript checks, and the production build.
